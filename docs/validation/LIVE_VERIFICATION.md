# 验证范围与限制

这是公开的验证范围说明，不包含真实账号的逐次验证日志。原始业务证据、资源标识和清理记录保存在开发机器的忽略目录 `logs/validation/`，不随源码或插件分发。

- 离线策略、输入校验、错误诊断、MCP 协议和打包测试不等于真实账号兼容性。
- 已有国际区训练模板／日历、未来目标／备注／赛事、部分心率／功率／显示单位及无使用记录装备操作的开发验证；不得据此宣称所有字段、数据形态和分页均已验证。
- 读取方法的响应兼容性概况见 [读取验证台账](READ_VERIFICATION.json)，任务判断方法见 [数据判断规则](TASK_VALIDATION.md)。
- 当前聊天的实际工具可用性必须在该会话验证；独立 MCP 或宿主发现成功不能替代。
- KI-001：FTHR 清空为 null 的契约未解决；0 不等于未设置。继续停止相关探测、清空和恢复测试，只有用户明确重开才继续；不作为当前交付阻塞。
- 国区业务与 Connect+ 专属功能延期；已使用装备、默认冲突、preferred defaults 等未经验证的写入契约仍保留限制。

真实验证需有具体用户任务和授权，并记录回读、原资源完整性与测试资源清理。不得将密码、token、个人响应或实际账号资源标识提交到公开文档。
